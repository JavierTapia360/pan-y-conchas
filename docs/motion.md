# Motion

- Hero reveal: 850ms, soft vertical entrance and image settle.
- Page transition: 500ms fade/10px rise.
- Scroll reveal: 650ms fade/24px rise.
- Cards: 380–600ms media zoom and metadata shift.
- Fullscreen menu: 550ms clip reveal with 70ms link stagger.
- Modal: opacity plus 2% scale.

All interactions remain interruptible. Native scroll is used on mobile. `prefers-reduced-motion` removes complex effects and keeps only immediate fades.
